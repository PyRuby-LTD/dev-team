# EPIC-003 Self-serve onboarding

**Depth: deferred - named theme, not decomposed**

Commercial-grade signup and credential handling, replacing the hand-held beta
process and the step where a user generates and pastes an on-track personal
access token.

Deferred because the beta is hand-held by agreement. Returns when on-track is
to be sold to the public.

Carries a known concern: asking non-technical athletes to generate and hand over
an access token is both an onboarding barrier and a credential-handling risk.
Acceptable with hand-holding; likely not acceptable commercially.
