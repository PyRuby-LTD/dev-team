## Agent skills

### Issue tracker

Specs and tickets are local markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels, recorded as a `Status:` line in each issue file. See `docs/agents/triage-labels.md`.

### Domain docs

Single context: `GLOSSARY.md` at the root, plus ADRs in `docs/adr/` reserved for hard-to-reverse or surprising decisions. See `docs/agents/domain.md`.
